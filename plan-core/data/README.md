# Biolink Model dependency

`biolink-model.yaml` is a downloaded dependency and is not stored in this
repository.

- Source: [Biolink Model](https://github.com/biolink/biolink-model)
- Required version: [`v4.4.3`](https://github.com/biolink/biolink-model/releases/tag/v4.4.3)
- License: [Apache 2.0](https://github.com/biolink/biolink-model/blob/master/LICENSE)

From the project root, run:

```bash
curl -fsSL \
  https://raw.githubusercontent.com/biolink/biolink-model/v4.4.3/biolink-model.yaml \
  -o plan-core/data/biolink-model.yaml
```
