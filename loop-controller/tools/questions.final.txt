# --- Unstable by nature. Do not trust this expectation. ---
# The name "neuropathic pain" does not resolve: the resolver returns 20
# specific syndromes and accepts none as the general term. What happens next
# is the planner's choice, and it has gone both ways across runs.
#
#   refused    — the planner declines to revise (needs_clarification) and the
#                loop stops on the unresolved name.
#   exhausted  — the planner repairs, picks a specific syndrome, and the new
#                hop shape turns out to be one ARAX cannot answer.
#
# Both are honest stopping points for the same underlying problem, so a flip
# between them is planner nondeterminism, not a regression. `refused` is the
# better of the two: it reaches the clarification answer.
#
